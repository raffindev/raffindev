## Featured Project

### [FundWatch — Financial Data Ingestion Pipeline](https://github.com/raffindev/fundwatch)

A Python backend project that processes public investment fund reports from the **Brazilian Securities and Exchange Commission (CVM)**.

The current **v0.1** focuses on CSV ingestion, data validation, PostgreSQL persistence, duplicate prevention, historical revisions, transaction control, and import auditing.

**Highlights from local validation (November 2026):**

- Processed and persisted **537,880 daily reports** from a real CVM dataset
- Registered **25,507 unique funds**
- **94 automated tests passing** with pytest in the recorded validation
- Uses **PostgreSQL 18** and **Psycopg 3** for relational persistence and transactions

**Current stage:** CLI-based ingestion pipeline. The REST API (FastAPI), Docker Compose, and CI are planned enhancements, **not yet implemented**.

`Python` `PostgreSQL` `Psycopg 3` `pytest` `Data Validation` `SQL`
